# JoshDavila.Art Structured Site

This package converts the existing hand-built GitHub Pages site into a
Jekyll site generated from structured career data.

## Source of truth

- `_data/profile.yml`
- `_data/projects.yml`
- `_data/writings.yml`
- `_data/exhibitions.yml`
- `_data/experience.yml`
- `_data/recognition.yml`
- `_data/support.yml`

## Generated public sections

- Home
- Works
- Research
- Writing
- Timeline
- Archive
- Biography and CV
- Support
- Individual project pages

Read `docs/MIGRATION.md` before replacing the live site.
